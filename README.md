## about
campus is designed to be a drop-in replacement housing for a framework 13 that features a kailh choc mechanical keyboard.

## disclaimer
campus is a highly involved project and will require completely tearing down your framework laptop and transplanting all the components into an objectively worse-designed chassis than the factory framework chassis. some features will be lost, for example, the privacy switches built into the webcam module, or the little buttons that lock the expansion cards in place. I am not a professional electronics designer, so expect to perform some janky workarounds to get the laptop functioning as it should. I am not responsible for any issues you may encounter with the build, so please use the files with caution.
