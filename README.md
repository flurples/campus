# campus
kailh choc mechanical keyboard conversion housing for a framework 13

## about
campus is designed to be a drop-in replacement housing for a framework 13 that features a hhkb layout kailh choc mechanical keyboard.

## you will need
- a framework 13 laptop
#### bottom chassis parts
- bottom chassis (cnc)
- bottom-bracket-R, L & M (3d print)
#### input cover parts
- input cover (cnc)
- plate (cnc)
- 3x knobs (cnc)
- 1x touchpad-clamp-R & L (3d print)
- 2x touchpad-clamp-top (3d print)
#### lid parts
- lid (cnc)
- bezel (3d print)
- lid-corner-cap-R & L (3d print)
#### other hardware
- 60x kailh choc switches
- choc stabilizers (2x 2u, 1x 6.25u)
- compatible keycaps (be sure to get 6.25u space, 1.75u shift, etc)
- 3x ec12 low profile encoders
- m1.6 x 3mm heat set inserts
- m2 x 4mm heat set inserts
- m2 x 2.5mm heat set inserts
- 5x m2 x 20mm flat head hex screws (to screw the chassis together)
- 4x 1" OD rubber bumpers
- variety of double sided tapes
- epoxy

## build notes
bottom chassis, input cover, lid, knobs, and plate were cnc'd from aluminum. all 3d printed parts were printed in petg to avoid breaking down over the years. heat set inserts for screw holes to mount factory components are installed into the bottom-brackets, which are then epoxied to the bottom-chassis. due to jlcpcb's minimum thickness requirements, the input and lid do not use heat set inserts. instead, the aluminum is directly tapped.

#### the keyboard workaround
the usb hub was too complex and I wasn't able to get it working. because the keyboard was originally meant to connect internally through the usb hub, I ended up simply bypassing the usb hub entirely, bypassing it with a unified daughterboard s1.
in case anyone wants to attempt to diagnose why, I've uploaded the kicad files as is for reference.

## disclaimer
campus is a highly involved project and will require completely tearing down your framework laptop and transplanting all the components into an objectively worse-designed chassis than the factory framework chassis. some features will be lost, for example, the privacy switches built into the webcam module, or the little buttons that lock the expansion cards in place. I am not a professional electronics designer, so expect to perform some janky workarounds to get the laptop functioning as it should.
